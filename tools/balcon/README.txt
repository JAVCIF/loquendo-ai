BALCON NO se redistribuye con Loquendo AI.

Descarga el ZIP oficial completo de Balabolka Command Line Utility (BALCON):
  https://www.cross-plus-a.com/es/bconsole.htm
y EXTRAE TODO
su contenido en esta carpeta; no copies solamente balcon.exe.

Ruta esperada:
  tools\balcon\balcon.exe

Las versiones actuales del paquete oficial también pueden traer DLL auxiliares como:
  libsamplerate.dll
  chsdet.dll
  SoundTouch.dll

Loquendo AI ejecuta BALCON con su propia carpeta como WorkingDirectory para que
pueda encontrar esos archivos.

Alternativamente define LOQUENDO_AI_BALCON con la ruta completa a balcon.exe.
